# 🔥 Ember & Oak — Wood-Fired Restaurant Website

A modern, high-converting, and fully responsive website template designed specifically for wood-fired restaurants, bistros, and cafés. Built with clean, modern web technologies.

##  Features

* **Dark & Light Mode:** Seamless theme toggle with persistent `localStorage` memory.
* **Interactive Menu Tabs:** Smooth category switching for Starters, Mains, and Drinks.
* **Table Reservation Form:** Secure date validation and instant interactive feedback.
* **Fully Responsive:** Optimized for mobile phones, tablets, and desktop screens.
* **Tailwind CSS Powered:** Modern utility-first styling for optimal performance.

##  Built With

* **HTML5** — Semantic and clean structure
* **Tailwind CSS** — Modern styling framework
* **JavaScript (Vanilla)** — Interactive components, tabs, and form validation

##  Files Included

* `index.html` — Main layout and markup
* `style.css` — Custom styles and theme variables
* `script.js` — Functionality for dark mode, menu filtering, and reservations
